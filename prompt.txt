ПАСПОРТ ПРОЕКТА: PWA «СкладРасклад»

ОПИСАНИЕ:
Мобильное PWA-приложение для составления отчётов об остатках iPhone. 
Пользователь выбирает модель, память и цвет, вводит количество. 
Приложение генерирует текст отчёта для отправки в рабочие чаты.

ТЕХНОЛОГИЧЕСКИЙ СТЕК:
- Frontend: HTML5, CSS3 (Flexbox, Grid), Vanilla JavaScript (без фреймворков).
- PWA: manifest.json + service worker (sw.js).
- Хранение: localStorage (ключи: sklad_grouped, sklad_history, theme).

UI/UX СТАНДАРТЫ (Native Feel):
1. Навигация: Две основные вкладки — 📦 СкладРасклад и 📜 История. 
2. Иерархия: Внутри первой вкладки есть переход в Редактор. Реализовано через History API (popstate), поддерживает системный свайп «Назад».
3. Шторки (Bottom Sheets): Все действия (темы, превью, подтверждения) выезжают снизу.
4. Выравнивание: Заголовки экранов прижаты влево. Контент главной страницы — строго по центру.
5. Кнопка «Назад»: Динамическая. Если скрыта, заголовок прижимается к левому краю (width: 0).
6. Счётчики (+ число -): Реализованы через display: grid. Число всегда идеально по центру. Спиннеры (стрелочки) удалены.

ЛОГИКА И АНИМАЦИИ:
1. Сортировка цветов: Обычные -> 💛 (Золотой/Пустынный) -> ❤️ (Красный). Красный всегда последний.
2. Нейминг 💛: «Пустынный» для 16 Pro, «Золотой» для Pro/XS, «Жёлтый» для остальных.
3. Плавность чипсов (Модели и Память): Цвет и масштаб меняются через CSS transition. Кнопки НЕ перерисовываются через innerHTML при клике, только переключаются классы .active.
4. Анимация Редактора: При смене модели карточка «прыгает» (card-jump-anim). При смене памяти список цветов плавно «всплывает» (list-pop-anim). Для запуска используется принудительный reflow (void el.offsetWidth).
5. Бегущая строка: Реализована для длинных названий моделей в режиме маятника (marqueeBounce).
6. Превью: Стилизовано под баббл сообщения Telegram (зелёный/синий).

ВАЖНЫЕ ДЕТАЛИ:
- Футер: «Священная фраза» («Первая в истории конторы приблуда...») должна быть отцентрована и иметь text-wrap: balance.
- Тосты: Контрастные плашки с размытием (Blur). На тёмной теме — синий фон. Время жизни 3.5 сек, плавное исчезновение.
- Пасхалка: При клике на пустую кнопку черновика срабатывает цикл ворчливых тостов.
- Система обновлений: Код в index.html слушает изменения в sw.js и предлагает перезагрузку при новой версии.

ИНСТРУКЦИЯ ДЛЯ ИИ:
При внесении правок в index.html категорически запрещено:
1. Менять логику обновления чипсов памяти на innerHTML (это ломает анимацию).
2. Сбивать центровку чисел в счётчиках (использовать только grid).
3. Удалять или изменять текст в футере.
4. Возвращать системные окна confirm/alert (использовать только существующие шторки).
