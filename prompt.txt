ПАСПОРТ ПРОЕКТА: PWA «СкладРасклад» (MASTER PROMPT)

ОБЩАЯ СУТЬ:
Мобильное PWA-приложение для составления складских отчётов по iPhone. 
Пользователь выбирает модель, память и цвет, указывает количество. 
Итог — текст отчёта, стилизованный под Telegram-сообщение.

1. ТЕХНОЛОГИЧЕСКИЙ СТЕК:
- Язык: Чистый HTML5, CSS3, Vanilla JavaScript.
- Архитектура: Объектно-ориентированный стиль (весь функционал внутри объекта `app`).
- Хранение: localStorage (ключи: sklad_grouped, sklad_history, theme).
- PWA: manifest.json (v4), service worker (sw.js v4).
- Навигация: History API (pushState/popstate). Системный свайп "Назад" должен возвращать к выбору, не закрывая приложение.

2. СТРОГИЕ ПРАВИЛА UI (iOS Style):
- Заголовки: Всегда по ЛЕВОМУ краю.
- Главный экран: Иконка, слоган и кнопки всегда строго по ЦЕНТРУ (вертикаль и горизонталь).
- Шторки (Bottom Sheets): Единственный вид модальных окон. Выезжают снизу. Системные alert/confirm ЗАПРЕЩЕНЫ.
- Счётчики (+ число -): Реализованы через display: grid. Число стоит мёртво по центру. Спиннеры (стрелочки) в инпутах вырезаны. Атрибут inputmode="numeric" обязателен.
- Статус-бар: Цвет theme-color обязан совпадать с фоном страницы (--bg-page). Синие или тёмные полоски под статус-баром недопустимы.
- Шторка тем: Кнопки-плашки со скруглением. Активная тема подсвечивается синим (--primary). Кнопка "Закрыть" внутри шторки не нужна.

3. АНИМАЦИИ И ПОВЕДЕНИЕ (Критически важно):
- Чипсы памяти: Находятся в ОДНОЙ СТРОКЕ с названием модели.
- Обновление памяти: КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО перерисовывать чипсы через innerHTML при клике. Обновлять только классы .active. Это сохраняет плавный transition цвета.
- Маятник (Marquee): Если название модели не влезает в строку из-за чипсов памяти, текст плавно едет до края и обратно (marqueeBounce).
- Переходы: При смене модели вся карточка "подпрыгивает" (card-jump-anim). При смене памяти список цветов "всплывает" (list-pop-anim).
- Авто-ноль: Если в поле количества оставить пустоту, при потере фокуса (onblur) там обязан снова появиться "0".
- Тосты: При быстром нажатии (спаме) старый тост мгновенно исчезает, а новый появляется (сброс через void element.offsetWidth).

4. ЛОГИКА ДАННЫХ И ТЕКСТЫ:
- Цвета: Сортировка: Стандартные -> 💛 -> ❤️ (Красный всегда последний). 
- Нейминг 💛: "Пустынный" для 16 Pro, "Золотой" для Pro/XS, "Жёлтый" для остальных.
- Пасхалка (на пустой черновик): Цикл тостов:
  1. «Здесь ничего нет»
  2. «Здесь всё ещё ничего нет»
  3. «Пусто тут, говорю»
  4. «ТУТ РЕАЛЬНО НИХУЯ НЕТ» (капсом)
- Футер: «Первая в истории конторы приблуда... Навайбкодил с любовью ❤️» (центрирование, balance).

5. СТАНДАРТ КНОПОК DANGER:
- Триггеры (Очистить/Удалить в списках): Стиль .btn-danger (белый/прозрачный фон, красная рамка).
- Подтверждение (Внутри шторок): Стиль .btn-danger-fill (красный фон, белый текст).
- Динамика: Кнопка "Очистить всю историю" видна только если история не пуста.

6. ЛОГИКА ЗАВЕРШЕНИЯ (Share/Copy):
- Из Редактора: Сохранить в историю -> Очистить склад -> Закрыть шторку -> На ГЛАВНУЮ. Тосты: "Отправлено и сохранено!" / "Скопировано и сохранено!".
- Из Истории: Выполнить действие -> Закрыть шторку -> ОСТАТЬСЯ в истории. Тосты: "Отправлено!" / "Скопировано!".
- Правка из истории: В шторке "Завершить" кнопка "Сохранить" - синяя (primary), кнопка "Поделиться" - белая (secondary).

7. ТЕХНИЧЕСКИЕ ОГРАНИЧЕНИЯ:
- Не использовать position: fixed для body (вызывает белый экран на мобильных).
- Скрипт быстрого фикса темы обязателен в начале body.
- Использовать только Vanilla JS, никаких библиотек.
